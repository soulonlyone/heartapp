# Windows 服务端控制面板

适合想在 Windows 上开服、给朋友共享地址的用户。面板使用暖白 D 版界面，
不需要打开命令行调整端口，也不需要安装完整心率客户端。

## 启动

独立文件夹版：打开 `HeartApp-Server-Panel/HeartApp-Server-Panel.exe`。
必须保留同目录的 `_internal` 文件夹，不能只复制 exe。

源码版：安装 `server/panel-requirements.txt` 后，双击仓库根目录 `启动服务端面板.bat`。
已有客户端开发环境可以直接启动，不需要重复安装依赖。

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r server/panel-requirements.txt
.venv\Scripts\python.exe -m heartapp.ui.qt.server_panel
```

## 从零开一个局域网房间

1. 监听范围选「局域网联机」，默认端口 `8765`、总连接上限 `20`、每房间 `4` 人。
2. 面板会生成随机访问密码，可点击「显示密码」查看或自行修改。
3. 点击「启动服务」，状态变成「运行中」才代表成功。
4. 从「局域网地址」选择朋友可访问的网卡地址，点击复制，另行发送访问密码。
5. 朋友在心率客户端的「联机房间」填写地址、昵称、密码，登录后创建或加入房间。
   每人分别开启共享，才能互相看到心率。

面板只列出 IPv4 局域网地址；多网卡、VPN 或虚拟网卡可能同时出现在下拉框中，
选择与朋友在同一网络的地址。初版不会自动修改 Windows 防火墙；必要时允许所选 TCP
端口入站。`127.0.0.1` 只供这台电脑自身测试，不能发给其他电脑使用。

## 各项设置是什么意思

| 设置 | 作用 |
|---|---|
| 局域网联机 | 监听 `0.0.0.0`，允许从本机 IPv4 网络接口连接 |
| 仅本机 / 反向代理 | 只监听 `127.0.0.1`，供本机客户端或同机反代使用 |
| 服务端口 | 1～65535，默认 8765；与防火墙、客户端地址保持一致 |
| 连接人数上限 | 已登录且在线的用户也占连接资源；默认 20，配置上限不等于压测容量 |
| 每房间人数 | 1～128，默认 4，受总连接上限约束 |
| 公网地址 | 可选，填写已有 HTTPS/WSS 反向代理地址；面板不会创建证书或自动做端口穿透 |

运行中锁定服务配置。要更换密码、端口或人数限制，先停止服务，修改后再启动。
停止会断开客户端并清空临时房间，各客户端自己的本地历史不受影响。

## 关闭与后台运行

- 系统托盘可用时，右上角关闭按钮会收起面板，服务继续运行。
- 双击托盘图标恢复面板；右键可以停止服务或彻底退出。
- 「退出面板」会先停止本面板的服务，再结束程序。
- 托盘不可用时，关闭窗口会停止服务并退出，避免出现找不到入口的后台实例。
- 初版没有「开机自动启动」开关。需要无人登录就开服时，使用 [原有 Windows 后台部署](README.md#windows)。
  不要同时启动后台服务与面板监听同一端口；面板不会接管其他进程。

## 密码、配置及诊断

设置保存在程序旁 `data/server-panel.json`，只保存端口、范围、人数和可选公网地址。
密码只在本次进程内使用，不写入配置；重开面板会重新生成，需要重新告知朋友。
配置目录无法写入时会阻止启动并提示重试，请将程序放到可写目录。

「运行信息」只保留最近 100 条状态提示，不记录昵称、房间码或心率；
「复制诊断」只包含版本、状态、人数和端口等，不包含密码。
如果系统拒绝剪贴板访问，面板会提示，可在地址框中选中地址手动复制。

房间密码尚未实现：访问密码保护整台服务器；同服登录用户可查看并加入未满房间。
服务运营者能接触经过转发的实时心率，只有信任的朋友才应获得访问密码。

## 常见问题

| 现象 | 处理 |
|---|---|
| 端口已被占用 | 先停止旧面板/后台服务，或改一个端口；不要盲目结束不认识的进程 |
| 本机能连、朋友不能连 | 核对网卡地址、监听范围、防火墙及是否处于同一局域网 |
| 运行中但公网不通 | 运行中只表示本机监听成功；仍需公网入口、证书、反代和网络放行 |
| 密码突然不一样 | 重开面板会重新生成；启动前确认当前密码 |
| 停止后房间消失 | 临时房间仅在内存，重新启动后由客户端重新创建 |

公网部署另见 [服务端总说明](README.md#公网与-tls)。Linux、Docker 的独立操作说明分别见
[Linux说明](Linux说明.md)、[Docker说明](Docker说明.md)。
