# HeartApp · D 版 PC 心率记录

## 已确认的产品方向

参考 Pulsoid 的即时心率显示体验，重点增加独立的 Windows 本地记录与历史曲线。
游戏过程中不要求用户操作或手动记录瞬间；小窗是核心功能。

## 视觉设计

采用用户选定的 D 版「数字海报」，见 [原始参考](design/reference-d.png)。
暖白底、墨色大号衬线心率数字、朱红数据线、细分隔与大留白。
主界面不使用侧边栏、统计卡片或运动表盘，连接控件收进独立对话框。
原生 Windows 窗框保留，便于正常拖动、缩放和最小化。

实时页左侧为当前心率，右侧为记录状态、时长、开始/停止与平均/最高/最低。
下方曲线可切换最近五分钟、三十分钟、本次全程；停止后仍能导出最近会话。
历史页左侧列表，右侧为完整曲线、缩放平移、悬停读数和 CSV 导出。
小窗以数字为主，细曲线与来源状态为辅；支持大小、透明度、鼠标穿透、位置记忆。
Ctrl+Alt+H 全局显示/隐藏小窗。注册失败会显示提示，仍可用主窗口按钮控制。

## 数据与交互约束

- 所有心率保存在本机 SQLite；模拟来源明确标注。
- 新界面不提供手动事件标记，也不突出基线、运动区间或 HRV；兼容数据和旧接口保留。
- 过期五秒的读数显示为空；未贴合读数不计入本次 GUI 统计。
- 采样事件携带采集端单调时间，GUI 不用接收队列的时间代替采集时间。
- 缺失区间在原始数据中分段，再按像素保留极值绘制，不对断流做插值。
- 历史页不能删除当前正在记录的会话。
- 置顶小窗面向窗口化/无边框游戏，独占全屏需实际游戏验证。

## 实现与验证

`editorial.py`：数字、曲线、小窗、按钮和全局快捷键。
`editorial_layout.py`：实时页、回看页、小窗设置、设备连接面板。
`app.py`：采集事件、统计、历史读取、导出。
旧 Tk 和 CLI 入口保持兼容，SQLite 表结构此次不变。

`tools/d_gui_preview.py` 只用合成数据生成实际 Qt 截图，保存在 `_test_output/design-d/`。
`tools/qt_smoke_test.py` 验证记录、历史、小窗、快捷键、设置和导出。
曲线回归测试覆盖四小时连续数据、真实缺口和缩放边界。

后续独立任务：真表长期运行、休眠恢复、保存失败退出保护、同设备手动重连和定时落库。
