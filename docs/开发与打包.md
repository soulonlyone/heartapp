# 开发与打包

**中文** | [English](development.en.md)

面向要改代码或自己打包的人。产品约定与踩坑记录见 [AGENTS.md](../AGENTS.md)。

## 环境

需要 Python 3.9+，用项目自带虚拟环境 `.venv`：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m heartapp --simulate    # 模拟数据，不需要手表
```

依赖只有三个：`PySide6-Essentials`（界面）、`bleak`（BLE，Windows 自动带 `winrt-*`）、
`websockets`（联机）。

## 测试

```powershell
.venv\Scripts\python.exe run_tests.py                       # 单元测试（当前 187 项）
.venv\Scripts\python.exe smoke_test.py                      # 后端全链路
.venv\Scripts\python.exe tools\qt_smoke_test.py             # 界面全流程（自动操作）
.venv\Scripts\python.exe tools\room_smoke_test.py           # 双客户端联机
.venv\Scripts\python.exe tools\server_panel_smoke_test.py   # 服务端面板
```

提交前至少跑前三项；改联机要加跑第四项，改面板加跑第五项。

界面截图可重新生成（只用合成数据，生成物不入库）：
`tools\d_gui_preview.py`、`tools\room_comparison_preview.py`、`tools\lobby_preview.py`。

## 打包

```powershell
.venv\Scripts\python.exe -m pip install pyinstaller
.venv\Scripts\python.exe tools\build_exe.py
```

产出 4 个文件（自动签名）：

```
dist\心率记录仪.exe                     单文件 · 图形界面
dist\心率记录仪-命令行.exe               单文件 · 命令行
dist\心率记录仪-便携版\图形界面版\...      文件夹版 · 图形界面（推荐分发）
dist\心率记录仪-便携版\命令行版\...        文件夹版 · 命令行
```

**两条硬约束，改配置时别动**：

1. **单文件版必须 `--runtime-tmpdir .`**
   默认解压到系统临时目录，部分机器会直接失败（`Could not create temporary directory!`，
   发生在 Python 运行之前，连日志都没有）。本机实测连 hello-world 单文件版都起不来。
   便携版不需要解包，不受影响，所以是推荐的下载方式。
2. **GUI 版排除 `tkinter`，CLI 版还要排除 `PySide6` + `shiboken6`**
   否则命令行版也有 37 MB。

## 发布

**一个版本只发一个 Release，客户端和服务端放在一起**：

```powershell
# 版本号在 heartapp/__init__.py，发布说明放 docs/release-notes/v<版本>.md
.venv\Scripts\python.exe tools\build_release.py
git tag -a v1.4.0 -m "..." && git push origin main v1.4.0
gh release create v1.4.0 --title "..." --notes-file "docs/release-notes/v1.4.0.md" dist\release\*
```

`build_release.py` 依次跑三个构建脚本、**统一签名**，组装到 `dist\release\` 并生成
覆盖全部产物的 `SHA256SUMS.txt`：客户端 3 个 + 服务端 3 个 + 服务端面板 1 个。

注意：

- 附件名必须 **ASCII**（中文名经 `gh` 上传会被截断成 `-.exe`）
- **签名要在压缩之前**，否则 zip/tar 里是未签名 exe
- `gh release upload --clobber` 是**先删后传**，大文件超时会让附件消失；逐个传并加重试

## 代码签名

自签名证书，本机信任后发布者显示 `HeartApp`。

| 项目 | 说明 |
|---|---|
| 证书 | `CN=HeartApp`，RSA 2048，10 年 |
| 私钥 | **不可导出** |
| 信任范围 | **只在本机有效** |
| SmartScreen | 仍可能提示（看下载量与声誉） |

打包脚本自动签名；手动用 `tools/bat/给exe签名.bat`，撤销用 `移除签名证书.bat`。
换商业证书见 [签名说明](签名说明.md)。

## 项目结构

```
heartapp/                      ★ 主包
├─ hr.py           0x2A37 帧解析 + 数据模型
├─ engine.py       采集引擎：asyncio 后台线程 + 事件队列
├─ store.py        SQLite 存储（含录制进程锁）
├─ paths.py        路径解析（数据一律在程序旁 data）
├─ cli.py          命令行
├─ relay.py        服务端入口        lobby.py      登录 / 房间 / 席位
├─ room_protocol.py 协议（纯函数）    room_client.py 客户端网络线程
└─ ui/qt/          ★ Qt 界面
   ├─ editorial.py / editorial_layout.py  D 版令牌 + 三页布局
   ├─ chrome.py    无边框窗口        app.py         主窗口 + 事件泵
   └─ room_panel.py / lobby_panel.py / comparison.py  联机相关
packaging/        PyInstaller 入口
server/           服务端部署（Docker / nginx / systemd / 管理菜单）
tools/            构建、签名、测试、截图脚本（bat/ 下是维护脚本）
tests/            单元测试
docs/             指南、签名说明、设计、发布说明
```

**分层纪律**：业务逻辑（hr / metrics / store / engine）不得 import 任何 UI 模块。

> `.bat` 必须 CRLF；`.ps1` 必须 UTF-8 with BOM。细节见 AGENTS.md。
