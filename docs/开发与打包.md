## 环境

需要 Python 3.9+。项目用独立虚拟环境 `.venv`（系统 Python 3.12 装不了 bleak 的旧版依赖）。

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m heartapp            # 启动界面
.venv\Scripts\python.exe -m heartapp --simulate  # 模拟数据，不需要手表
```

依赖只有三个：

| 包 | 用途 |
|---|---|
| `PySide6-Essentials` | 界面（Qt 6） |
| `bleak` | BLE（Windows 上会自动带 `winrt-*`） |
| `websockets` | 联机客户端与转发服务 |

## 启动脚本

| 脚本 | 位置 | 作用 |
|---|---|---|
| `启动心率记录仪.bat` | 根目录 | 从源码启动界面 |
| `启动心率记录仪(模拟演示).bat` | 根目录 | 源码 + 模拟模式 |
| `运行测试.bat` | `tools/bat/` | 单元 + 后端 + 界面冒烟 |
| `启动联机服务.bat` | `tools/bat/` | 启动本机转发服务（局域网联机） |
| `启动服务端面板.bat` | 根目录 | 启动可视化服务端控制面板 |
| `联机本机演示.bat` | `tools/bat/` | 起服务和两个模拟玩家，用独立演示数据库 |
| `给exe签名.bat` | `tools/bat/` | 给 `dist\` 里的 exe 签名 |
| `移除签名证书.bat` | `tools/bat/` | 撤销本机信任的自签名证书 |
| `GitHub命令.bat` | `tools/bat/` | 调用本地 gh CLI（建仓 / 推送） |

> `.bat` 必须用 **CRLF** 换行。编辑器存成 LF 会让 `cmd.exe` 截断中文提示。

## 测试

```powershell
.venv\Scripts\python.exe run_tests.py              # 当前 171 个单元测试
.venv\Scripts\python.exe smoke_test.py             # 后端全链路
.venv\Scripts\python.exe tools\qt_smoke_test.py    # 界面全流程（自动操作）
.venv\Scripts\python.exe tools\room_smoke_test.py  # 双客户端联机全流程
.venv\Scripts\python.exe tools\server_panel_smoke_test.py # 服务端面板与失败恢复
```

提交前至少跑前三个；改了联机代码要跑第四个。
面板改动还需跑第五个。它使用独立配置和本机服务，截图在 `_test_output/server-panel/`；
不会注册系统计划任务或修改防火墙。打包独立面板使用 `tools/build_server_panel.py`，
只需 `server/panel-requirements.txt` 和 PyInstaller；分发整个 `dist/HeartApp-Server-Panel`。

界面截图可以重新生成（只用合成数据，不读个人记录，生成物不入库）：

```powershell
.venv\Scripts\python.exe tools\d_gui_preview.py            # D 版主界面
.venv\Scripts\python.exe tools\room_comparison_preview.py  # 多人对比
.venv\Scripts\python.exe tools\lobby_preview.py            # 联机大厅
```

## 打包

```powershell
.venv\Scripts\python.exe -m pip install pyinstaller
.venv\Scripts\python.exe tools\build_exe.py
```

一次产出 4 个文件（会自动调用签名脚本）：

```
dist\心率记录仪.exe                        单文件 · 图形界面
dist\心率记录仪-命令行.exe                  单文件 · 命令行
dist\心率记录仪-便携版\图形界面版\...         文件夹版 · 图形界面
dist\心率记录仪-便携版\命令行版\...           文件夹版 · 命令行
```

**两个打包上的硬约束**，改配置时别动：

1. **单文件版使用 Windows 临时目录解包**

   单文件版启动时由 PyInstaller 解压到系统临时目录，持久数据另存于用户目录。
   便携版（文件夹版）不需要解包，是**推荐的下载方式**；单文件版解压到 exe 旁边。数据一律写在 `程序目录\data`。

2. **GUI 版排除 `tkinter`，CLI 版还要排除 `PySide6` + `shiboken6`**
   （`tkinter` 已无代码引用，排除只是为了瘦身）
   否则命令行版也会变成 37 MB。

## 发布

**一个版本只发一个 Release，客户端和服务端放在一起**，不按端拆成两个。

```powershell
# 版本号在 heartapp/__init__.py，发布说明放 docs/release-notes/v<版本>.md
.venv\Scripts\python.exe tools\build_release.py
```

它依次跑客户端、服务端、服务端面板三个构建脚本，**统一签名**，
再把产物组装到 `dist\release\` 并生成一份覆盖全部文件的 `SHA256SUMS.txt`：

| 文件 | 内容 |
|---|---|
| `HeartApp-v<版本>-win64.exe` / `-win64-cli.exe` / `-win64-portable.zip` | 客户端 |
| `HeartApp-Server-v<版本>-win64.exe` / `-linux.tar.gz` / `-docker.tar.gz` | 服务端 |
| `HeartApp-Server-Panel-v<版本>-win64.zip` | 服务端面板（Windows） |
| `SHA256SUMS.txt` | 全部文件的校验和 |

然后：

```powershell
git tag -a v1.2.0 -m "..."
git push origin main v1.2.0
gh release create v1.2.0 --title "HeartApp v1.2.0 · ..." --notes-file "docs/release-notes/v1.2.0.md" dist\release\*
```

注意事项：

- 附件名必须 **ASCII**，中文名经 `gh` 上传会被截断成 `-.exe` 之类。
- **签名要在压缩之前**，否则 zip / tar 里是未签名的 exe。`build_release.py` 已按此顺序。
- 用 `gh release upload --clobber` 替换附件时它是**先删后传**；大文件传超时会让附件凭空消失，
  重传即可，最好逐个文件传并加重试。

## 代码签名

exe 带自签名证书，本机信任后发布者显示 `HeartApp`。

| 项目 | 说明 |
|---|---|
| 证书 | 自签名 `CN=HeartApp`，RSA 2048，10 年 |
| 私钥 | **不可导出**，无法拷到别的电脑冒充 |
| 信任范围 | **只在本机有效**，换台电脑仍显示未知发布者 |
| SmartScreen | 仍可能提示（看下载量和声誉，不看签名） |

打包脚本会自动签名。手动：双击 `tools/bat/给exe签名.bat`。
撤销：双击 `tools/bat/移除签名证书.bat`。
换商业证书的完整步骤见 [签名说明](签名说明.md)。

```

├─ 启动心率记录仪.bat            源码启动（唯一的用户入口）
├─ 启动心率记录仪(模拟演示).bat   源码 + 模拟模式
├─ run_tests.py                 单元测试入口
├─ smoke_test.py                后端全链路冒烟
├─ requirements.txt
├─ heartapp/                    ★ 主包
│  ├─ hr.py          0x2A37 帧解析 + 数据模型
│  ├─ ble.py         真实手表数据源
│  ├─ simulator.py   模拟数据源
│  ├─ engine.py      采集引擎：asyncio 后台线程 + 事件队列
│  ├─ store.py       SQLite 存储
│  ├─ metrics.py     统计
│  ├─ paths.py       路径（区分源码 / exe 运行）
│  ├─ cli.py         命令行
│  ├─ room_protocol.py  联机协议（纯函数）
│  ├─ lobby.py          服务端：登录 / 房间目录 / 席位
│  ├─ relay.py          服务端入口（独立 asyncio）
│  ├─ room_client.py    客户端网络线程
│  ├─ room_history.py   队友曲线缓存（内存，30 分钟）
│  └─ ui/
│     ├─ qt/          ★ Qt 界面（默认）
│     │  ├─ editorial.py        D 版设计令牌 + 自绘控件
│     │  ├─ editorial_layout.py 三页布局 + 连接对话框
│     │  ├─ chrome.py           无边框窗口按钮与缩放
│     │  ├─ room_panel.py       联机弹窗与多人小窗
│     │  ├─ lobby_panel.py      服务器登录 / 房间列表
│     │  ├─ comparison.py       多人同坐标曲线
│     │  └─ app.py              主窗口 + 事件泵
├─ packaging/                   PyInstaller 入口
├─ server/                      联机服务端（Docker / compose / nginx 示例）
├─ tools/
│  ├─ build_exe.py              打包 4 个产物（自动签名）
│  ├─ sign_exe.ps1              自签名
│  ├─ make_icon.py              生成图标
│  ├─ qt_smoke_test.py          界面冒烟
│  ├─ room_smoke_test.py        双客户端联机冒烟
│  ├─ room_demo.py              双模拟客户端演示
│  ├─ d_gui_preview.py          界面截图（合成数据）
│  ├─ room_comparison_preview.py
│  ├─ lobby_preview.py
│  └─ bat/                      维护脚本（测试 / 签名 / 联机 / GitHub）
├─ tests/                       单元测试
└─ docs/
   ├─ 使用指南.md
   ├─ 开发与打包.md
   ├─ 签名说明.md
   ├─ pc-monitor-design.md
   ├─ merge-handoff.md
   ├─ release-notes/
   └─ images/                   界面截图
```

**分层纪律**：业务逻辑（hr / metrics / store / engine）不得 import 任何 UI 模块。
两个界面共享同一套逻辑层，改逻辑时两边都要能跑。
