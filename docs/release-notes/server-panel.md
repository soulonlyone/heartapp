# Windows 服务端面板与三端说明（待合并、待发布）

在 `codex/server-distribution-fixes` 基础上新增 Windows 可视化面板，保留协议 v2，
不改个人数据库。当前分支同时包含上一轮 Docker/Windows 启动器修复。

## 功能

- D 版暖白、无边框窗口、胶囊按钮；端口、密码、连接人数和房间容量直接设置。
- 显示本实例运行状态、在线登录人数、房间数及运行时长。
- 生成随机密码；只在当前进程使用，不写配置、日志、诊断或地址邀请。
- 本机地址、IPv4 局域网网卡选择、可选公网 WSS 地址，复制地址不含密码。
- 托盘可用时关闭窗口继续运行，托盘可打开、停止和退出。托盘不可用时关闭会先停服。
- 不自动检测公网可达性、不安装证书或修改防火墙、不接管已有后台实例。
- 房间由客户端管理，面板不显示或保存成员心率、昵称、房间码。

`heartapp/server_control.py` 使用独立 asyncio 线程复用原转发核心；界面在
`heartapp/ui/qt/server_panel.py`。Linux、Docker 无需 Qt，原命令行入口保持不变。

## 入口与文档

- 源码：根目录 `启动服务端面板.bat`。
- 独立构建：`tools/build_server_panel.py`，输出整个 `dist/HeartApp-Server-Panel/`。
- 操作说明：`server/Windows面板说明.md`、`server/Linux说明.md`、`server/Docker说明.md`。

面板依赖单列在 `server/panel-requirements.txt`，无需安装 BLE 依赖。
独立包使用 Qt，因此体积会明显大于纯命令行服务；包体不上传 Git，应走 Release 附件。
Windows 构建子进程收窄 PATH，避免把其他应用的不兼容 ICU DLL 混入 Qt 包；不修改系统 PATH。
当前本地包是开发测试构建，发布前还需签名及独立目标机验收。

## 验证与限制

新增 8 项控制器/配置测试，覆盖真实登录统计、停止重启、端口占用后重试、
后台异常、立即停止、无凭据配置与保存失败。全量 167 项测试通过。
原后端、Qt 客户端、双客户端联机和新面板冒烟均通过。
独立 exe 已在本机通过打开窗口、点击启动、HTTP 健康检查、点击退出和端口释放检查。
面板冒烟还覆盖配置失败、非法端口、最小化、托盘收起恢复、退出，以及拒绝剪贴板访问的提示；
复制内容使用剪贴板替身验证，自动化桌面不保证系统剪贴板可用。

说明书中的 Linux systemd、Docker、WSS 为部署流程说明，本轮未安装系统服务、
修改防火墙、在真实 Docker 引擎构建或做公网压测。Windows 面板初版没有开机自启开关，
需要无人登录开服时继续使用原 Windows 后台部署脚本。

Linux/Docker 分发压缩包同步带上三端说明与 Nginx 片段，方便解压后直接阅读。
