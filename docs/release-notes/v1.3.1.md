## 修复

### 英文 / 非中文 Windows 上点「开始记录」会崩溃

生成默认会话名时用了：

```python
datetime.now().strftime("游戏记录 %m-%d %H:%M")
```

Windows 的 `strftime` 会按**系统 ANSI 代码页**编码整个格式串。中文系统（cp936）
没问题，但英文系统（cp1252）等区域会抛 `UnicodeEncodeError`，表现为点一下
「开始记录」程序就崩。

v1.3.1 改为纯 ASCII 格式串 + 字符串拼接，并新增防回归测试：
扫描源码，禁止 `strftime` 的格式串里出现非 ASCII 字符。

> 中文系统的用户不受此问题影响，但仓库已公开，国外用户会遇到，所以按补丁版发布。

### 其他健壮性修复

- 界面冒烟里「导出到无权限目录会自动兜底」的用例改为注入异常，
  不再依赖运行账号权限（CI 的 runner 是管理员，连 System32 都能写）
- 后端冒烟允许「停止记录」边界上 1–2 条的事件/落库时序差，并新增
  会话统计与实际落库条数**严格相等**的断言
- 两个在不同 Windows 区域设置下会误报失败的测试

## 已知限制（未变）

- 广播心率每秒 1 次，不是逐拍；HRV 只能当参考
- 只支持标准 BLE 心率服务，厂商私有协议读不到
- 独占全屏会遮挡小窗，快捷键可能被游戏占用
- 公网 WSS / 反向代理尚未验证
- 未做各游戏的反作弊兼容认证（软件不注入、不读内存、不采集输入）
