## 文件管理：数据只在程序旁边

以前单文件版会在 exe 旁边生成 `data` 和 `_MEI` 两个文件夹，还在用户目录里留东西。现在：

- **数据库一律放在 `程序目录\data\heartrate.db`**，便携版、单文件版、源码运行都一样
- **不在 `%LOCALAPPDATA%` 等用户目录里新建任何文件**
- 只有程序目录不可写时（装在 `Program Files`、只读 U 盘）才退回用户目录兜底
- 更早版本若把库放在用户目录，启动时自动迁回程序目录（保留原文件，校验后原子替换）

> 便携版是推荐下载：不用解包、启动更快，文件夹里只有你自己的 `data`。

## 新增：小窗预设

单人小窗和联机小窗共用一套缩放、透明度、鼠标穿透设置，并新增：

- 图片背景、调色盘、曲线显示时长与粗细
- **可保存多个小窗预设**（含位置），随时切换
- 预设里的背景图片引用本地文件路径

## 客户端改进

- 主窗口默认 860 × 600
- 实时页支持「上次设备」快捷连接
- 断开连接、停止记录前有确认
- 保存后直接跳到本次回看
- 回看悬停显示真实采样时间

## 联机改进

- 服务端下发**每房容量**，默认 4 人，可设 1–128（实际受总连接上限约束）
- 创建区和房间列表直接显示容量
- 服务器地址支持 `IP:端口` 或 `域名:端口` 简写；裸地址带非 443 端口按 `ws://` 连接
- 多人小窗固定展示 4 人，主界面图例可滚动查看其余队友

## 服务端改进

- Linux 安装向导：终端隐藏输入密码，确认端口后安装
- 新增 `sudo heartapp-server` 管理菜单：启停服务、看日志、改密码、改端口、改每房容量
- **安装目录 `/opt/heartapp-relay` 改为 root 所有**，服务用户只读执行——
  避免服务被攻陷后替换 Python 解释器、在管理员执行管理命令时提权

## 修复

- 扫描设备时不再覆盖连接状态
- 停止采集超时会明确报错，不再导致退出卡住
- 录制时对数据库加进程锁，防止两个实例同时写同一个库

## 兼容性

- 协议仍为 v2，**新客户端可以连旧服务端**
- 旧客户端连新服务端时，若房间容量超过 4 人会报错；开放大房间前请两端一起升级

## 已知限制（未变）

- 广播心率每秒 1 次，不是逐拍；HRV 只能当参考
- 只支持标准 BLE 心率服务，厂商私有协议读不到
- 独占全屏会遮挡小窗，快捷键可能被游戏占用
- 公网 WSS / 反向代理尚未验证；Linux 安装向导的真实 systemd 环境仍需实测
- 未做各游戏的反作弊兼容认证（软件不注入、不读内存、不采集输入）
