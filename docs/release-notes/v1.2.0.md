**新增联机房间：和队友在同一张图上比较心率。**

从「一个人记录」扩展到「几个人一起看」。服务器可以自己部署，也可以只用局域网。

## 新增：联机房间

「实时」主页新增「**联机房间**」入口：

- 填服务器地址（域名 / IPv4 / IPv6）+ 昵称 + 访问密码（服务端设置了才需要）
- **服务器登录与房间分开**：退房后仍保持登录，可以直接换房；主动退出服务器才登出
- 创建房间拿到 8 位房间码，或从房间列表直接加入（最多 4 人）
- **每个人自己决定是否共享**，默认关闭；模拟读数会明确标注
- 加入后主页自动切换为**多人同坐标曲线**：固定颜色图例、可单独开关、悬停看同一时刻读数
- **多人小窗**：每人一行，昵称 + 当前心率 + 最近 60 秒曲线，同一纵轴刻度

**数据边界**（这些是刻意设计的）：

- 队友曲线只在内存保留最多 30 分钟，退出房间立即清空，**不写入本地数据库**
- 服务端**不保存心率历史**
- 密码与会话令牌**不落盘**，重启软件要重新登录
- 断线会清空过期读数并重连；服务器挂了不影响本地采集和保存

## 新增：自己部署服务器

仓库里带一整套服务端（`server/`）：

- 独立 Python 服务，**不需要 Qt / BLE / 数据库**
- 提供 `Dockerfile`、`docker-compose.yaml`、`nginx` 反向代理示例
- 默认只监听 `127.0.0.1:8765`，建议放在 HTTPS 反代后面暴露 WSS
- 局域网最省事：双击 `启动联机服务.bat`

**没有提供的公共服务器** —— 联机需要你自己部署，或者用局域网直连。

## 其他改进

- **无边框窗口**：自绘窗口按钮，支持顶部拖动、双击最大化、四边缩放
- **主窗口最小化时游戏浮窗保持显示**（Windows 会隐藏父窗口的子浮窗，这里改成独立顶层窗口）
- **独立定时保存**：不再依赖"有新样本才写库"；数据提交使用 FULL 同步
- **退出保存保护**：保存失败会取消退出并保留缓存，不会关了库再试图补写
- **重启后历史恢复**：异常终止的记录能读回已提交的数据

## 修复

- 圆角下拉菜单在 Windows 深色模式下**四角发黑**
- Windows 联机启动脚本的换行符（LF 会被 `cmd.exe` 截断中文提示）

## 兼容性

- **协议 v2 与 v1 不兼容**，客户端和服务端需要一起升级
- 服务端房间/会话/令牌都是内存状态，重启即清空，重新创建房间即可
- **SQLite 表结构未变**，旧数据库可直接沿用

## 已知限制

- **独占全屏游戏会盖住浮窗**，请把游戏改为无边框窗口模式
- 曲线按接收时间**近似对齐**，包含网络延迟，不等于逐拍同步
- 公网 WSS、证书、反向代理超时**尚未验证**，部署到公网需要你自己测
- 未做各游戏反作弊兼容认证；软件不注入、不读内存、不采集输入
- 置顶小窗与 Ctrl+Alt+H 可能被部分游戏占用

## 系统要求

Windows 10 / 11，蓝牙适配器支持 BLE 4.0+。
联机功能需要能访问你部署的服务器（或同一局域网）。
