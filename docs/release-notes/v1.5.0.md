## 服务端：一个命令入口

```
heartapp-server install      安装 / 重新配置（--dry-run 可预演）
heartapp-server uninstall    卸载
heartapp-server status       配置、服务状态、健康检查
heartapp-server config       查看/修改配置
heartapp-server cert         IP 证书 setup / renew / status
heartapp-server menu         交互菜单
```

安装失败会**自动回滚**（单元、配置、版本指针、服务状态），不会再留下半截状态。

## 这个版本修了什么

- **版本目录权限 0755**：修复 v1.4.4 的 `Changing to the requested working directory failed: Permission denied`（`mkdtemp` 默认 0700 导致服务用户进不去）
- **卸载命令**：`heartapp-server uninstall`，支持保留配置、删除用户、预演
- **配置收敛**：单一 JSON 文件，旧版 `.env` + `ExecStart` 自动迁移
- **`acme` 子命令恢复**：证书模块和 CI 冒烟依赖它
- **预发布版被装成旧版**：`deploy.sh` 改为优先读仓库 `server/LATEST`
- **一键安装命令简化**：单条 curl + 镜像自动回退

## 安装（Linux）

```sh
cd /tmp && rm -rf heartapp-server-* srv.tgz
curl -fsSL --max-time 120 "https://ghfast.top/https://github.com/soulonlyone/heartapp/releases/download/v1.5.0/HeartApp-Server-v1.5.0-linux.tar.gz" -o srv.tgz
tar -xzf srv.tgz && cd heartapp-server-1.5.0
sudo ./runtime/heartapp-server install --package-root .
```

详见 [服务端部署指南](https://github.com/soulonlyone/heartapp/blob/main/docs/服务端部署指南.md)。

## 已知限制

- 自动 IP 证书需要独占 TCP 80；机器上有 nginx 等情况请用反代模式
- 证书每 12 小时检查续期，续期时同样需要 80
- 明文模式（`ws://`）密码与心率在网络上可见，仅建议可信网络
- Docker 容器与公网 WSS 压测仍未验收
