**首个正式版本。**

从智能手表实时读取心率并记录到本地的 Windows 工具。免安装，双击即用。

---

## 下载

| 文件 | 说明 |
|---|---|
| **`心率记录仪.exe`** | **单文件版，双击就用**（推荐） |
| `心率记录仪-便携版.zip` | 文件夹版。解压后运行 `图形界面版\心率记录仪.exe`，启动快、杀软误报少 |
| `心率记录仪-命令行.exe` | 命令行版，排查故障用 |

> 单文件版每次启动会解压到 exe 旁边，请放在**可写目录**（桌面/文档/U 盘），
> 不要放在 `C:\Program Files`，也不要用「以管理员身份运行」。

## 功能

- **实时读取**：蓝牙 BLE 直连，标准 Heart Rate Service（`0x180D`）/ 特征 `0x2A37`
- **不绑定品牌**：OPPO / 华为 / 小米 / 三星 / Garmin 等，只要广播标准心率即可
- **实时曲线**、心率区间统计（Z1–Z5）、静息心率、HRV（参考值）
- **本地存储**：SQLite，历史记录浏览与曲线回放，数据全部在本机
- **CSV 导出**：带 UTF-8 BOM，Excel 双击不乱码
- **模拟模式**：没有手表也能完整体验（三种运动场景）
- **命令行**：扫描 / 设备探针 / 记录 / 导出

## 界面

克制风格（near-monochrome + 唯一强调色），白卡 + 发丝描边 + 极轻投影。
表盘、趋势图、区间条全部 `QPainter` 矢量绘制，抗锯齿，跟随系统 DPI 缩放。
PySide6 缺失时自动降级到 Tkinter 界面。

## 说明

- exe 带自签名代码签名（发布者显示 `HeartApp`）。首次运行 SmartScreen 仍可能提示，
  点「更多信息」→「仍要运行」即可
- 数据保存在 exe 旁边的 `data\` 目录，不上传任何服务器
- 导出 CSV 若提示没有权限，用「导出 CSV → 导出到数据目录」

## 系统要求

Windows 10 / 11，蓝牙适配器支持 BLE 4.0+。
