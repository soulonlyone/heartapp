**服务端开箱即用：Windows 可视化面板 + Linux 一行安装。**

这个版本把「自建服务器」从"要懂命令行"变成"双击或一行命令"，
并且**客户端和服务端从这一版起放在同一个 Release 里**。

---

## 下载

| 文件 | 用途 |
|---|---|
| **`HeartApp-v1.3.0-win64.exe`** | **客户端单文件版，双击就用**（推荐） |
| `HeartApp-v1.3.0-win64-portable.zip` | 客户端文件夹版，启动快、误报少 |
| `HeartApp-v1.3.0-win64-cli.exe` | 客户端命令行版，排查故障用 |
| `HeartApp-Server-Panel-v1.3.0-win64.zip` | **服务端面板（Windows）**，可视化开服 |
| `HeartApp-Server-v1.3.0-win64.exe` | 服务端独立 exe，不需要装 Python |
| `HeartApp-Server-v1.3.0-linux.tar.gz` | Linux 源码包（配合 `install-linux.sh`） |
| `HeartApp-Server-v1.3.0-docker.tar.gz` | Docker 构建包 |
| `SHA256SUMS.txt` | 全部附件的 SHA256 校验和 |

> 只做单机记录的话，**只需要客户端那三个文件之一**，服务端是可选的。

## 新增：Windows 服务端面板

以前开服务器只能敲命令，现在有图形界面：启动 / 停止、设置访问密码、
复制连接地址、显示在线人数、最小化到托盘。

下载 `HeartApp-Server-Panel-v1.3.0-win64.zip`，解压后双击 `HeartApp-Server-Panel.exe`。
它独立运行，**不会**接管你已有的系统服务；退出时只停自己启动的实例。

## 新增：Linux 一行安装

```sh
curl -fsSL https://raw.githubusercontent.com/soulonlyone/heartapp/main/server/deploy.sh \
  | sudo bash -s -- --password '你的口令'
```

脚本会：查最新版本 → 下载服务端包 → **校验 SHA256** → 解压 → 装到 `/opt/heartapp-relay`
并注册 systemd 服务。

- `--dry-run` 只看会做什么，不实际安装
- `--port` / `--max-clients` / `--room-size` / `--version` 都要得
- 不放心管道安装，可以先 `curl -fsSLO` 下载下来看一眼

## 新增：一个 Release 装全部

之前客户端和服务端分两个 Release，不好对应版本。现在一个版本一个 Release，
客户端、服务端、服务端面板放在一起，`SHA256SUMS.txt` 一份覆盖全部。

## 改进

- **服务端启动器可移植**：不再依赖仓库目录结构，解压到哪都能跑
- **Unicode 密码**：服务端访问密码支持中文和特殊字符
- 发布流程脚本化（`tools/build_release.py`），签名在压缩之前，避免包内是未签名文件

## 隐私与开源

- 仓库历史已做脱敏：个人设备地址与称呼已替换，旧根目录截图的全部历史版本已移除
- 新增 **MIT 许可证**：自用、修改、商用、分发都可以，保留版权声明即可

## 已知限制（未变）

- 广播心率每秒 1 次，不是逐拍；HRV 只能当参考
- 只支持标准 BLE 心率服务，厂商私有协议读不到
- 独占全屏会遮挡小窗，快捷键可能被游戏占用
- 公网 WSS / 反向代理尚未验证
- 未做各游戏的反作弊兼容认证（软件不注入、不读内存、不采集输入）

## 系统要求

Windows 10 / 11，蓝牙适配器支持 BLE 4.0+。
联机需要能访问你自建的服务器（或同一局域网）。
