# 服务端 P0 安全加固验收

本分支基于 main 的 462f90f，应用了 DSH 交接补丁。

- Linux 新装默认仅监听 127.0.0.1。命令行在非环回地址启动时需要 TLS 证书或显式传入 `--allow-plaintext`。
- Linux 安装向导要求至少 8 位密码，拒绝常见弱密码和全同字符。健康检查仅返回 OK。
- Docker 和 Windows 原有局域网入口显式传入明文参数，以兼容现有部署。公网使用 WSS。

188 项测试以及后端、Qt、联机和服务端面板冒烟测试通过。用重建的 Linux 压缩包在 WSL Ubuntu systemd 实测安装、健康检查、双客户端登录和心率转发，并验证了本机证书校验下的 WSS。测试使用离线依赖。Docker 容器和公网 WSS 仍待验收。

发布前还需处理一行安装在缺少校验时继续执行，以及升级时先执行旧目录 pip 再收紧目录权限的问题。
