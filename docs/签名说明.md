# 代码签名说明

本文说明 exe 的签名是怎么来的、能做到什么、做不到什么，以及怎么换成商业证书。

---

## 1. 现状

4 个 exe 都带**自签名代码签名**，本机信任该证书后，Windows 显示的发布者是
**HeartApp**，而不是「未知发布者」。

```
签名状态：Valid
签名者  ：CN=HeartApp, O=HeartApp, C=CN
```

## 2. 这张证书是哪来的

**在本机现场生成的，不是任何机构签发的。**

用 Windows 自带的 `New-SelfSignedCertificate`（见 `tools/sign_exe.ps1`），
生成后把公钥证书装进当前用户的「受信任的根证书颁发机构」。
没有任何第三方为它背书 —— 从证书本身就能看出来：

```
主体 = 颁发者 = CN=HeartApp, O=HeartApp, C=CN   ← 自签名
证书链长度 = 1                                   ← 中间没有 CA
```

| 项目 | 说明 |
|---|---|
| 证书 | 自签名，`CN=HeartApp, O=HeartApp`，RSA 2048，有效期 10 年 |
| 私钥 | **不可导出**（`-KeyExportPolicy NonExportable`），无法拷到别的电脑冒充 |
| 私钥位置 | `Cert:\CurrentUser\My`，受当前用户账户保护 |
| 信任范围 | **只在本机有效**。换台电脑仍显示未知发布者 |
| SmartScreen | **仍可能提示**。它看的是下载量/声誉，不是签名本身 |
| 受控文件夹访问 | 签名不保证放行，仍建议把 exe 加进白名单 |

### 安装到「受信任根」意味着什么

**本机信任任何用这张私钥签名的程序。**

这是自签名的固有代价。私钥不可导出只能防止「拷到别的电脑冒充」，
防不了「本机已被控制」—— 但那种情况下攻击者直接替换 exe 更省事。

## 3. 重新签名

`tools/build_exe.py` 打包完成后会**自动调用**签名脚本。

也可以随时手动签：

```bat
双击  tools/bat/给exe签名.bat
```

脚本会：找证书（没有就生成）→ 导出 `.cer` → 确认本机已信任 → 签名 → 复核。

## 4. 想要「全球都信任」

必须买**商业代码签名证书**：

| 类型 | 价格 | 说明 |
|---|---|---|
| OV（个人/组织） | 约 ¥1000–2000/年 | 需身份证或营业执照审核，签发 3–7 天 |
| EV | 约 ¥3000+/年 | 硬件 UKey，能更快积累 SmartScreen 声誉 |

拿到 `.pfx` 后：

```powershell
# 导入（会提示输入密码）
Import-PfxCertificate -FilePath 你的证书.pfx -CertStoreLocation Cert:\CurrentUser\My

# 查指纹
Get-ChildItem Cert:\CurrentUser\My | Where-Object Subject -like '*你的名字*'

# 签名（务必带时间戳）
$cert = Get-ChildItem Cert:\CurrentUser\My | Where-Object Thumbprint -eq <指纹>
Get-ChildItem dist -Recurse -Filter *.exe | ForEach-Object {
    Set-AuthenticodeSignature $_.FullName -Certificate $cert -HashAlgorithm SHA256 `
        -TimestampServer "http://timestamp.digicert.com"
}
```

**时间戳很重要**：带上它，证书过期后已经签名的 exe 仍然有效；不带的话
证书一过期，签名就全部失效。

> 即使是商业证书，SmartScreen 对新程序仍可能有短暂提示 —— 需要累积下载量。

## 5. 证书在哪、怎么撤

```
heartapp-selfsigned.cer            ← 公钥证书（可拷给别人安装，已 gitignore）
Cert:\CurrentUser\My\<指纹>         ← 私钥证书（签名时用）
Cert:\CurrentUser\Root\<指纹>       ← 受信任根（本机信任它的依据）
```

查看当前状态：

```powershell
Get-ChildItem Cert:\CurrentUser\My   | Where-Object Subject -like '*HeartApp*'
Get-ChildItem Cert:\CurrentUser\Root | Where-Object Subject -like '*HeartApp*'
Get-ChildItem dist -Recurse -Filter *.exe | Get-AuthenticodeSignature
```

撤销信任：

```bat
双击  tools/bat/移除签名证书.bat
```

或手动删除 `Cert:\CurrentUser\Root` 与 `Cert:\CurrentUser\My` 里对应指纹的证书。
移除后 exe 会恢复「未知发布者」，并且打包脚本不再自动签名（找不到证书就跳过）。

## 6. 安全提醒

- 自签名证书的**私钥在本机**，不要发给别人，也不要把证书存储导出分发。
- 如果要把整个项目文件夹拷给别人，先删掉 `.tools\`（里面有 GitHub CLI 的 token）。
